caravan. Interactive demo · synthetic data, no real patients

The passenger seat of care.

Caravan is a concept check-in system built from a front desk’s point of view: an age-friendly phone check-in for patients, and a web app for the desk that flags problems and lets people decide.

  • Every screen is the real, working app
  • Each file just opens on a different screen
  • Click around: buttons, keys and forms all work
