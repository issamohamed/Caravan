What gets logged

  • Every record link or merge, with the reason
  • Every skipped step or overridden check
  • Every import, row by row
  • Every question-set edit and publish
  • Every phone check-in and help request

Why reasons are required

A reason turns "someone changed it" into something a supervisor can check later. It also shows which rules staff keep working around, so the clinic can fix the rule.
